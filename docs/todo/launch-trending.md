## How the badges work

- **GitHub Trending** ranks repos by stars gained in a day/week, per language (Bou counts as
  Java). There is no badge from GitHub itself; sites like Trendshift track the ranking.
- **Trendshift** (trendshift.io) watches trending repos and gives an embeddable
  "#N Repository Of The Day" badge once a repo ranks. Then we add its badge to the README.
- Rough target: 30-60 new stars within 24 hours is often enough for the Java daily list.
- Never buy stars, use star-exchange groups or fake accounts. GitHub removes fake stars and can
  flag the repo; the badge would then be a lie on the owner's name.
